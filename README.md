# 🎓 LearnSpace — Online Course Platform

## 📌 Overview

**LearnSpace** is a modern, interactive online course platform built using **HTML, CSS, and JavaScript**. It allows users to explore courses, filter content, save favorites, and enroll in courses through a simple and intuitive interface.

The project simulates a real-world learning platform with features like user login, course enrollment, and dynamic UI updates.

---

## 🚀 Features

### 🔍 Course Exploration

* Browse 20+ courses across multiple categories
* Search courses by name or topic
* Filter courses by difficulty level

---

### 🧩 Smart UI & Interaction

* Dynamic course rendering
* Expandable course modules
* Smooth animations and responsive design

---

### ⭐ Saved Courses

* Save/unsave courses
* View saved courses in a side panel
* Persistent storage using localStorage

---

### 🔐 User Login System

* Simple login system using localStorage
* Stores user details (name, email, phone)
* Personalized experience after login

---

### 🎯 Course Enrollment

* Enroll in courses with a single click
* No repeated data entry after login
* Experience level selection during enrollment
* Prevents duplicate enrollments

---
